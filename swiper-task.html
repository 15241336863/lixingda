帮我用 Swiper 的 creative effect 做"电影选片墙"效果——上一张幻灯片缩小左移带旋转、下一张放大右移进场。效果配置对象叫 creativeEffect，参数：prev.scale=0.82, rotate=[0,0,-12], translate=['-35%',0,-300]；next.scale=1.08, rotate=[0,0,12], translate=['35%',0,-300]；origin 分别 left center 和 right center。
// ✅ creativeEffect 配置对象
var lxd_creativeFx = {
  prev: { shadow: true, origin: "left center", translate: ["-35%", 0, -300], rotate: [0, 0, -12], scale: 0.82, opacity: 0.55 },
  next: { shadow: true, origin: "right center", translate: ["35%", 0, -300], rotate: [0, 0, 12], scale: 1.08, opacity: 1 },
  perspective: true, limitProgress: 2
};

transform 逐字段解析（答辩必问）

translate: [x, y, z]
X 水平 / Y 垂直 / Z 景深（需 perspective:true）；数值可 px 或 % 字符串，"-35%" 相对容器宽度
rotate: [x, y, z]
X 水平翻 / Y 立体转 / Z 平面转（单位度）；prev 用 -12 顺时针右倒，next 用 +12 逆时针左倒
scale: 数字
缩放倍数，1=原大；prev 0.82 缩小退场、next 1.08 放大进场
opacity: 数字
透明度 0~1；prev 0.55 半透明若隐若现、next 1 完全清晰
origin: 字符串
变换原点（CSS transform-origin 格式）；prev 用 "left center" 左边钉住、next 用 "right center" 右边钉住
perspective: true
开启 3D 透视，translateZ 和 rotateX/Y 才会生效

transform 里的百分号相对谁？

相对 Swiper 容器本身的宽度，不是幻灯片本身。translate:["-35%",0,-300] 的 -35% ≈ -266px（容器 760px × 0.35），刚好推到容器左缘外。

改一个数值让卡片转 20 度？

把 rotate:[0,0,-12] 改成 rotate:[0,0,-20]（prev），rotate:[0,0,12] 改成 rotate:[0,0,20]（next）。Z 轴数值越大角度越大，正负号决定顺/逆时针。

🗣️ 答辩抽问准备（点击展开）▼
transform 里的百分号相对谁的？
相对 Swiper 容器（swiper 元素本身）的宽度，不是幻灯片。比如 translate:['-35%',0,-300] 的 -35% 就是容器宽度 × 0.35。
改一个数值让卡片转 20 度试试？
prev 的 rotate:[0,0,-12] → rotate:[0,0,-20]，next 的 rotate:[0,0,12] → rotate:[0,0,20]。Z 轴数值越大角度越大，正负号决定方向。
prev / next 的 transform 各控制什么？
prev 控制"正在离开"的幻灯片：缩小+左移+顺时针倒+后退+半透明；next 控制"即将进场"的：放大+右移+逆时针倒+后退+完全不透明。两者对称，形成电影选片墙的立体堆叠感。

超纲能力：keyboard 键盘控制

帮我在 #wySw4 上加 Swiper 的 keyboard 键盘控制能力，让方向键能切换。注意页面有 7 个效果按钮，点击会 destroy + new Swiper 重建实例——重建的新配置里也必须带上 keyboard，否则切一次效果键盘就失效了。用 { enabled: true } 对象形式。
// ✅ 初始配置 + 按钮重建配置 都要加 keyboard

var lxd_newConfig = {
  loop: true, effect: lxd_currentFx,
  keyboard: { enabled: true }    // ← 两处都不能漏！
};

🗣️ 答辩四连问准备（点击展开）▼
这段代码什么意思？
keyboard:{enabled:true} 是 Swiper 键盘控制模块配置。开启后 Swiper 会在 document 上监听 keydown：按 → 调 slideNext() 切下一张，按 ← 调 slidePrev()。配了 loop:true 所以最后一张按 → 无缝回第一张。
AI 第一次给的哪里不对、你改了什么？
第一次只给了简写 keyboard:true 且只改初始化一处。问题：① 简写不规范，对象形式才能扩展（比如 onlyInViewport）；② 更关键的是按钮切换时会 destroy+new 重建实例，lxd_newConfig 里没带 keyboard，切一次效果键盘就失效。我把它补进了重建配置。
新参数的作用？
keyboard.enabled 控制键盘监听开关；Swiper 默认还有 onlyInViewport:true（轮播在视口内才响应，防止页面多个轮播互相抢键盘）。本页只有 wySw4 开了键盘，不影响其他 3 个轮播。
现场把 delay 改成指定值并解释预期变化？
把 autoplay:{delay:3200,...} 里的 3200 改成老师指定值（比如 1000），预期每张停留从 3.2s 变 1s 自动翻页明显变快；disableOnInteraction:false 不变所以手动后 1s 继续自动翻。两处（初始+重建）都要改，否则切效果后速度又变回 3.2s。
