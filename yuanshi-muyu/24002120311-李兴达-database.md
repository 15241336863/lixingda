## 一、建表 SQL

```sql
-- 商品表
CREATE TABLE IF NOT EXISTS lxd_products (
  lxd_id INTEGER PRIMARY KEY AUTOINCREMENT,
  lxd_name TEXT NOT NULL,
  lxd_cat TEXT NOT NULL,
  lxd_price REAL NOT NULL DEFAULT 0,
  lxd_stock INTEGER NOT NULL DEFAULT 0,
  lxd_sales INTEGER NOT NULL DEFAULT 0,
  lxd_rating REAL NOT NULL DEFAULT 5,
  lxd_img TEXT DEFAULT '',
  lxd_desc TEXT DEFAULT '',
  lxd_sub TEXT DEFAULT '',
  lxd_old REAL DEFAULT 0,
  lxd_tag TEXT DEFAULT ''
);

-- 分类表
CREATE TABLE IF NOT EXISTS lxd_categories (
  lxd_id INTEGER PRIMARY KEY AUTOINCREMENT,
  lxd_key TEXT NOT NULL UNIQUE,
  lxd_name TEXT NOT NULL,
  lxd_icon TEXT DEFAULT ''
);

-- 订单表
CREATE TABLE IF NOT EXISTS lxd_orders (
  lxd_id INTEGER PRIMARY KEY AUTOINCREMENT,
  lxd_no TEXT NOT NULL UNIQUE,
  lxd_user TEXT NOT NULL,
  lxd_amount REAL NOT NULL DEFAULT 0,
  lxd_status TEXT NOT NULL DEFAULT '待发货',
  lxd_created_at TEXT NOT NULL
);

-- 用户表
CREATE TABLE IF NOT EXISTS lxd_users (
  lxd_id INTEGER PRIMARY KEY AUTOINCREMENT,
  lxd_username TEXT NOT NULL UNIQUE,
  lxd_password_hash TEXT NOT NULL,
  lxd_salt TEXT NOT NULL,
  lxd_nickname TEXT DEFAULT '',
  lxd_created_at TEXT NOT NULL
);
```

## 二、字段说明

### 1. lxd_products（商品表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| lxd_id | INTEGER | 主键，自增；接口中的商品 id |
| lxd_name | TEXT | 商品名称，必填 |
| lxd_cat | TEXT | 所属分类标识，对应 lxd_categories.lxd_key（living/bedroom/dining/office） |
| lxd_price | REAL | 现价（元） |
| lxd_stock | INTEGER | 库存 |
| lxd_sales | INTEGER | 销量 |
| lxd_rating | REAL | 评分（0-5） |
| lxd_img | TEXT | 图片文件名，前端按 `img/<文件名>` 引用 |
| lxd_desc | TEXT | 商品描述 |
| lxd_sub | TEXT | 副标题（前端卡片副文案，扩展字段） |
| lxd_old | REAL | 原价/划线价（扩展字段） |
| lxd_tag | TEXT | 促销标签：热卖/新品/爆款/套装（扩展字段） |

> 说明：任务要求的核心字段已全部包含；`lxd_sub`、`lxd_old`、`lxd_tag` 为保持前台商品卡片与详情页展示效果而扩展的字段。

### 2. lxd_categories（分类表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| lxd_id | INTEGER | 主键，自增 |
| lxd_key | TEXT | 分类业务标识，唯一，仅小写字母/数字/短横线 |
| lxd_name | TEXT | 分类名称，如“客厅系列” |
| lxd_icon | TEXT | 分类图标文件名，如 living.png |

### 3. lxd_orders（订单表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| lxd_id | INTEGER | 主键，自增 |
| lxd_no | TEXT | 订单号，唯一，如 DD20261127101 |
| lxd_user | TEXT | 下单用户昵称 |
| lxd_amount | REAL | 订单金额（元） |
| lxd_status | TEXT | 状态：待付款/待发货/配送中/已签收/退款售后 |
| lxd_created_at | TEXT | 创建时间，格式 `YYYY-MM-DD HH:mm:ss` |

### 4. lxd_users（用户表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| lxd_id | INTEGER | 主键，自增 |
| lxd_username | TEXT | 用户名，唯一 |
| lxd_password_hash | TEXT | 密码哈希（`crypto.scryptSync(password, salt, 64)` 的 hex 结果） |
| lxd_salt | TEXT | 随机盐（16 字节 hex），每个用户独立 |
| lxd_nickname | TEXT | 昵称 |
| lxd_created_at | TEXT | 注册时间，格式 `YYYY-MM-DD HH:mm:ss` |

## 三、种子数据说明

初始化逻辑位于 `backend/db/lxd_sqlite.js`，按以下顺序执行，且每类数据仅在对应表为空时导入：

1. **分类**：读取 `data/categories.json`，共 4 条（客厅/卧室/餐厅/办公），从 `link` 中解析 `cat` 作为 `lxd_key`。
2. **商品**：读取 `data/products.json`，共 20 件，按文件顺序插入，自增 id 为 1-20；`rate` 写入 `lxd_rating`，`sub/old/tag` 一并写入扩展字段。
3. **订单**：共 13 条，其中 3 条历史订单（7 天以前）用于陈旧数据展示，另有 10 条分布在近 7 天，用于后台分页与趋势图演示；订单号以 `DD202610...` / `DD20261127...` 开头，状态覆盖 5 种状态。
4. **用户**：若 `lxd_username = 'lixingda'` 不存在，则创建默认管理员：
   - 用户名：`lixingda`
   - 密码：`123456`（scrypt 加盐哈希后存储，数据库内无明文）

> 重复启动服务不会重复插入（导入前先 `SELECT COUNT(*)` 判断）。

## 四、如何据此重建数据库

1. 删除旧库文件（谨慎操作，会丢失后台新增数据）：

```text
backend/db/muyu.db
```

2. 在 `backend` 目录启动服务，脚本会自动重新建库、建表并导入种子数据：

```powershell
D:\兼职\node.exe server.js
```

启动日志会输出：

```text
[lxd_db] 数据表初始化完成：...\backend\db\muyu.db
[lxd_db] 分类种子数据导入完成：4 条
[lxd_db] 商品种子数据导入完成：20 条
[lxd_db] 订单种子数据导入完成：13 条
[lxd_db] 默认管理员已创建：lixingda / 123456
```

3. 也可直接执行附录中的建表 SQL 手动建表，再按 `data/*.json` 内容插入数据；默认管理员需自行用 scrypt 生成盐与哈希。

## 五、附录：常用查询

```sql
-- 商品总数 / 库存 / 销量
SELECT COUNT(*) AS n, SUM(lxd_stock) AS stock, SUM(lxd_sales) AS sales FROM lxd_products;

-- 分类商品数量分布
SELECT c.lxd_key AS key, c.lxd_name AS name,
       (SELECT COUNT(*) FROM lxd_products p WHERE p.lxd_cat = c.lxd_key) AS count
FROM lxd_categories c ORDER BY c.lxd_id;

-- 近 7 天订单趋势
SELECT substr(lxd_created_at, 1, 10) AS d, COUNT(*) AS n, SUM(lxd_amount) AS amount
FROM lxd_orders
WHERE substr(lxd_created_at, 1, 10) >= date('now', '-6 day')
GROUP BY d ORDER BY d;
```
