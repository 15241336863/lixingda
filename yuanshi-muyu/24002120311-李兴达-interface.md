# 木语家居接口文档

> 姓名：李兴达 | 学号：24002120311 | 时间：2026-11-27 | 大模型：DeepSeek-V4.1-Flash
> 服务地址：`http://localhost:8311`，统一前缀 `/api`
> 所有接口返回统一结构：`{ "code": 0, "message": "ok", "data": ... }`；`code` 非 0 表示失败。
> 列表数据统一为：`{ "total": 总数, "list": [], "page": 当前页, "size": 每页条数 }`。
> 需要登录的接口在请求头携带：`Authorization: Bearer <token>`；未登录或 token 无效返回 HTTP 401 + `{ "code": 401, "message": "未登录", "data": null }`。

---

## 一、前台公开接口

### 1. 商品分页列表

- **路径**：`GET /api/products/list`
- **请求参数**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| page | number | 否 | 页码，默认 1 |
| size | number | 否 | 每页条数，默认 8，最大 100 |
| cat | string | 否 | 分类标识，如 living / bedroom / dining / office |
| kw | string | 否 | 关键词，匹配名称、描述、副标题 |
| sort | string | 否 | 排序：hot（销量）/ priceUp / priceDown / new，默认按 id 升序 |

- **请求示例**

```text
GET /api/products/list?page=2&size=8&cat=living&kw=沙发
```

- **响应示例**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "total": 20,
    "list": [
      {
        "id": 9,
        "name": "实木梳妆台",
        "cat": "bedroom",
        "price": 1999,
        "stock": 44,
        "sales": 876,
        "rate": 4.7,
        "img": "dresser.jpg",
        "desc": "自带化妆镜，三抽收纳，桌角圆润，卧室梳妆两相宜。",
        "sub": "带镜·三抽收纳",
        "old": 2499,
        "tag": "新品"
      }
    ],
    "page": 2,
    "size": 8
  }
}
```

- **路径**：`GET /api/products/detail`
- **请求参数**：`id`（number，必填，商品主键 id）
- **请求示例**：`GET /api/products/detail?id=3`

  "message": "ok",
  "data": {

    "name": "皮质单人休闲沙发",
    "cat": "living",

    "stock": 40,
    "sales": 934,

    "old": 2699,

- **失败示例**：`{ "code": 404, "message": "商品不存在", "data": null }`

### 3. 商品搜索

- **路径**：`GET /api/products/search`
- **请求参数**：`kw`（string，必填）、`page`、`size`
- **请求示例**：`GET /api/products/search?kw=沙发&page=1&size=8`
- **响应示例**：与商品列表一致，`total` 为命中数量，`kw` 为空时返回空列表。

### 5. 用户登录

- **路径**：`POST /api/user/login`
- **请求体**

```json
{ "username": "lixingda", "password": "123456" }
```

- **成功响应**

```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "eyJ1aWQiOjEsImV4cCI6MTc5NTg3NTA2MTQ5OH0.18XSUGqcm_MNaXG1CPAzRWeLnii1Lck3OHw26BQ0KXg",
    "user": {
      "id": 1,
      "username": "lixingda",
      "nickname": "李兴达",
      "createdAt": "2026-11-27 22:10:17"
    }
  }
}
```

- **失败示例**：`{ "code": 400, "message": "用户名或密码错误", "data": null }`

### 6. 用户注册

- **路径**：`POST /api/user/register`
- **请求体**

```json
{ "username": "13800000000", "password": "abc123", "nickname": "小木" }
```

- **成功响应**

```json
{
  "code": 0,
  "message": "注册成功",
  "data": { "id": 2, "username": "13800000000", "nickname": "小木", "createdAt": "2026-11-27 22:20:00" }
}
```

- **校验规则**：用户名 3-20 位字母/数字/下划线且唯一；密码 6-20 位；密码以 scrypt 加盐哈希入库。
- **失败示例**：`{ "code": 400, "message": "该用户名已注册", "data": null }`

## 二、后台接口（均需 token）

### 7. 后台商品分页列表

- **路径**：`GET /api/admin/products/list`
- **请求参数**：`page`、`size`、`kw`（匹配名称/描述/副标题）、`cat`
- **请求示例**：`GET /api/admin/products/list?page=1&size=5&kw=沙发`
- **响应示例**：同商品列表结构 `{ total, list, page, size }`。
- **未登录响应**：HTTP 401 + `{ "code": 401, "message": "未登录", "data": null }`

### 8. 新增商品

- **路径**：`POST /api/admin/products/add`
- **请求体示例**

```json
{
  "name": "测试实木边几",
  "cat": "living",
  "price": 599,
  "stock": 30,
  "sales": 0,
  "rating": 4.8,
  "img": "sideboard.jpg",
  "desc": "接口测试新增商品",
  "sub": "测试·边几",
  "old": 799,
  "tag": "新品"
}
```

- **成功响应**：`{ "code": 0, "message": "新增成功", "data": { "id": 21, "name": "测试实木边几", ... } }`

### 9. 编辑商品

- **路径**：`PUT /api/admin/products/:id`
- **请求体**：任意字段子集，未传字段保持原值
- **请求示例**

```text
PUT /api/admin/products/21
{ "price": 688, "stock": 25, "tag": "热卖" }
```

- **响应示例**：`{ "code": 0, "message": "更新成功", "data": { "id": 21, "price": 688, ... } }`

### 10. 删除商品

- **路径**：`DELETE /api/admin/products/:id`
- **响应示例**：`{ "code": 0, "message": "删除成功", "data": { "id": 21 } }`

### 11. 后台分类列表

- **路径**：`GET /api/admin/categories/list`
- **请求参数**：无
- **响应示例**：`{ "code": 0, "message": "ok", "data": { "total": 4, "list": [ { "id": 1, "key": "living", "name": "客厅系列", "icon": "living.png", "count": 5 } ], "page": 1, "size": 4 } }`

### 12. 新增分类

- **路径**：`POST /api/admin/categories/add`
- **请求体**

```json
{ "key": "test-cat", "name": "测试分类", "icon": "products.png" }
```

- **成功响应**：`{ "code": 0, "message": "新增成功", "data": { "id": 5, "key": "test-cat", "name": "测试分类", ... } }`

### 13. 编辑分类

- **路径**：`PUT /api/admin/categories/:id`
- **请求体**：`{ "name": "测试分类改" }`（key 修改时需保持唯一且符合小写字母/数字/-）
- **响应示例**：`{ "code": 0, "message": "更新成功", "data": { "id": 5, "name": "测试分类改", ... } }`

### 14. 删除分类

- **路径**：`DELETE /api/admin/categories/:id`
- **响应示例**：`{ "code": 0, "message": "删除成功", "data": { "id": 5 } }`
- **限制**：分类下仍有商品时返回 `{ "code": 400, "message": "该分类下还有 N 件商品，不能删除", "data": null }`

### 15. 后台订单分页列表

- **路径**：`GET /api/admin/orders/list`
- **请求参数**：`page`、`size`、`status`（待付款/待发货/配送中/已签收/退款售后）、`kw`（匹配订单号/用户）
- **请求示例**：`GET /api/admin/orders/list?page=1&size=5&status=待发货`
- **响应示例**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "total": 2,
    "list": [
      { "id": 5, "no": "DD20261127102", "user": "张一凡", "amount": 1462, "status": "待发货", "createdAt": "2026-11-26 10:16:00" }
    ],
    "page": 1,
    "size": 5
  }
}
```

### 16. 新增订单（扩展）

- **路径**：`POST /api/admin/orders/add`
- **请求体**

```json
{ "user": "接口测试用户", "amount": 888, "status": "待发货" }
```

- **成功响应**：`{ "code": 0, "message": "新增成功", "data": { "id": 14, "no": "DD1795788672766356", "user": "接口测试用户", "amount": 888, "status": "待发货", "createdAt": "2026-11-27 22:11:12" } }`

### 17. 修改订单状态

- **路径**：`PATCH /api/admin/orders/:id`
- **请求体**：`{ "status": "配送中" }`（仅允许上述 5 种状态）
- **响应示例**：`{ "code": 0, "message": "状态已更新", "data": { "id": 1, "no": "DD20261001001", "status": "配送中", ... } }`

### 18. 删除订单（扩展）

- **路径**：`DELETE /api/admin/orders/:id`
- **响应示例**：`{ "code": 0, "message": "删除成功", "data": { "id": 14 } }`

## 三、错误码约定

| code | HTTP | 说明 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 400 | 200 | 参数校验失败 / 业务限制（如重复用户名、分类下有商品） |
| 401 | 401 | 未登录或 token 无效、过期 |
| 404 | 200 | 资源不存在 |
| 500 | 500 | 服务器内部错误 |
