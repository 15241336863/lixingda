# 木语家居家具保养指南

## 一、实木家具保养

实木家具采用天然木材制作，保养得当可使用 20 年以上。日常保养要点如下：
1. 避免长时间阳光直射。阳光会使木材表面油漆老化、变色，建议在窗户上安装遮光帘；
2. 保持适宜湿度。最理想的室内湿度为 45%-55%，冬季干燥时使用加湿器，雨季使用除湿机；
3. 定期用干布擦拭。每周用微纤维干布擦拭一次，去除浮尘；每月用专用实木家具蜡或核桃油擦拭一次，补充木材油脂；
4. 避免重物撞击。实木家具受力有一定限度，切忌用重物磕碰边角或站在家具上取物；
5. 远离热源。不要把暖气片、电热器直接放在家具旁，温度骤变会导致木材开裂。

## 二、布艺沙发保养

布艺沙发面料多为棉麻或涤纶混纺，保养时需注意：
1. 每周吸尘。使用吸尘器的软毛刷附件清理缝隙，防止灰尘沉积滋生螨虫；
2. 可拆洗套子按洗标洗涤。建议冷水手洗或选择洗衣机的轻柔模式，不要使用漂白剂和柔顺剂；
3. 及时处理污渍。饮料、食物等液体溅出时，用干净纸巾吸干表面水分（不要来回擦拭），再用专用布艺清洁剂局部清洗；
4. 避免尖锐物品。不要在沙发上使用剪刀、回形针等尖锐物品，防止勾丝；
5. 定期翻转坐垫。沙发坐垫长期受压容易变形，建议每两周翻转一次，延长使用寿命。

## 三、皮艺沙发保养

皮艺沙发质感高级，价格也更高，保养需要更细心：
1. 每月使用皮革护理剂。在清洁皮面后均匀涂抹护理剂，用软布擦拭至光亮；
2. 避免阳光和空调直吹。皮革长时间被阳光直射或干燥风吹，容易龟裂变硬；
3. 防止污渍渗透。液体溅出要立即处理，因为皮革有一定吸水性，污渍停留时间越长越难清除；
4. 远离尖锐边角。皮带扣、钥匙等金属物品容易划伤皮面，坐下前注意取出；
5. 冬季注意保暖。皮革在低温下会变硬变脆，建议保持室内温度在 10℃ 以上。

## 四、岩板茶几养护

岩板茶几硬度高、耐高温，但仍需注意以下几点：
1. 虽然岩板耐高温（可达 1200℃），但仍建议在高温锅具下放隔热垫，避免温差过大导致开裂；
2. 避免使用尖锐刀具直接在岩板上切菜，虽然不会刮花岩板，但刀具容易崩口；
3. 每日用清水擦拭即可，顽固污渍可用中性清洁剂（如洗洁精）配合湿抹布擦拭；
4. 不要使用钢丝球、百洁布等硬质清洁工具，虽然岩板表面不会刮花，但会留下难以去除的摩擦痕迹；
5. 安装时要确保台面受力均匀，不要在一角长期放置重物。

## 五、通用保养原则

所有木语家居商品都遵循以下保养原则：
- 使用与材质匹配的清洁工具，不要跨界使用；
- 定期保养比一次性深度保养更重要；
- 遇到疑难污渍，先在不显眼处测试清洁产品再使用；
- 长期不在家时，建议用防尘罩覆盖家具；
- 保养有疑问时，可联系木语家居客服获取专业建议。
